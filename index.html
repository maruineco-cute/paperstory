背景（1枚 or 複数スロット）

ユーザーが用意した背景画像を使います。端末内で処理され、サーバーには送信されません。

単色の背景色

スロットを選ぶと「開始時の背景」になります。セリフごとの背景切替も「セリフ」タブから可能です。

立ち絵は透過PNG（APNG対応）を推奨。アニメGIF・アニメWebPもそのまま動きます（短いループ推奨）。プレビュー内で直接ドラッグ移動、±ボタンやスライダーで拡大縮小できます。編集画面は左右に余白があるので、余白をドラッグしてスクロールしてください。

テキストでまとめて入力

1行に1セリフ。 名前｜表情番号｜セリフ｜効果
効果は ハート / 花 / キラキラ / ほわほわ / ハートきらめき。
背景は ＞背景番号 の行で（次のセリフから切替）、地｜ で地の文です。

番号の一覧・効果の書き方を見る

追加後も、各セリフの行をタップすれば話者・効果音・選択肢などを個別に編集できます。

1行ずつ追加（話者を選んで入力）

すぐ追加するだけならこれでOK。表情・効果音など詳細は追加後にその行をタップして編集してください。

JSON 一括入出力

例：[{"name":"晴真","text":"会いたかった","effect":"heart"}]
effect は heart / sparkle / soft（ほわほわ～）、slot は表情キー、visible は表示するキャラ名の配列です。
地の文は {"type":"narration","text":"…","position":"middle","narStyle":"theme"}（position は上/中央/下、narStyle は clear/window/theme）。
選択肢は {"name":"晴真","text":"どっち？","choices":[{"text":"猫","jump":1},{"text":"犬","jump":2}]}（jump はジャンプ先の行番号・0始まり）。

会話ウィンドウのデザイン

表示オプション

名前を表示するキャラ名のプレートを出します

動画アプリ用セーフエリア

TikTokなどは画面の下側と右側にUIが重なり、セリフが隠れます。
プリセットを選ぶと、セリフ枠がその分だけ自動で内側へ移動します。

編集画面に枠を表示斜線の部分がアプリのUIで隠れます
再生画面にも枠を表示確認用。録画するときはOFFに

再生中は右上の「枠」ボタンでも表示を切り替えられます（長押しでボタンが出ます）。
録画するときは「設定 → 画面への収め方」を画面いっぱいにすると、動画アプリ側で黒帯が切られません。

再生時の表示

録画時は端末に合わせて選んでください。iPhoneの縦画面(9:19.5)では「画面いっぱい」を選ぶと黒帯なしで録画できます（背景が端末の比率に合わせて広がり、セリフは画面幅いっぱいに表示されます）。9:16ちょうどの動画にしたい場合は「ぴったり収める」を使います。

自動送り

自動送り指定秒数で次のセリフへ自動進行（タップでも進められます）

終了演出（録画用）

待っている間は最後のセリフがそのまま表示されます（録画の余韻用）。
待ち時間中はタップしても何も起きません（最後のセリフのまま。✕で編集に戻れます）。

文字表示

1文字ずつ表示タイプライター風に出します（タップで全文表示）
キャラの揺れ（全体）キャラごとのON/OFFは「キャラ・立ち絵」タブで設定できます

効果音（SE）

「セリフ」タブでセリフごとにSEを指定できます（地の文にも使えます）。端末内で処理され、サーバーには送信されません。

プロジェクトの保存・読み込み

画像・SEもJSONに含まれます。自動保存はこの端末のブラウザ内（localStorage）にのみ行われます。

📱 録画してSNSに投稿する手順
  • この画面の「▶ 再生」をタップすると、9:16のステージだけが全画面表示になります（黒帯を消したい場合は設定→画面への収め方＝「画面いっぱいに埋める」）。
  • iPhone：コントロールセンター → 画面収録（マイク音声も使えます）→ 開始 → 会話をタップで進める → 収録停止。
  • Android：クイック設定 → 画面録画 → 開始 → 同様に進める。
  • PC：Windows は Win + G、macOS は Shift + Cmd + 5、OBS などでも可。
  • 録画後、そのまま TikTok / YouTube Shorts / Instagram へアップロードできます。
  • メモ：PCの場合はブラウザの全画面（F11）を使うとUIが消えて収録しやすくなります。
🧭 使い方の基本
  • 背景：画像を追加、または単色／なし。スロットを選ぶと開始時の背景になります。
  • 立ち絵：透過PNG（APNGも可）を表情ごとに登録。プレビュー内でドラッグ＝移動（キャラ・立ち絵タブ時のみ）、＋／−＝拡大縮小、⇄＝左右反転、前面／背面＝表示順。
  • 揺れ：再生中は呼吸するように少し揺れます。キャラごとにON/OFFでき、全体のON/OFFは設定タブにあります。
  • セリフ：順番に登録。「話者」「表情」「本文」「エフェクト(heart / sparkle)」を指定します。
  • 地の文：セリフの種類を「地の文」にすると、話者なしで描写文を表示します。位置・背景も指定できます。
  • 選択肢：セリフに選択肢（最大4つ）とジャンプ先を追加すると、再生中にボタンが出て分岐します。2択だけでゲーム感がでます。
  • 再生：画面タップで次のセリフへ。最後まで進むと「もう一度」が出ます。設定→自動送りで秒数指定の自動進行も可能です。
  • SE：設定→効果音で音声ファイルを登録し、「セリフ」タブでセリフごとに指定します（地の文にも指定可）。
  • 作業内容はこの端末のブラウザに自動保存されます（サーバー送信・ログインはありません）。
ℹ️ このツールについて（仕様メモ）

HTML / CSS / JavaScript だけで動作し、サーバー不要・GitHub Pages にそのまま置けます。 画像はブラウザ内でのみ処理されます（アップロード・保存なし）。
将来拡張の受け皿として：背景スロット（複数・セリフ毎切替に一部対応済み）、 キャラクターデータの in / out（入退場）、shake（画面揺れ）、 fade（フェード）、BGM / SE 用のフックをコード内に用意しています。
